A travel poster for Lumaris, a floating archipelago of gardens above a sea of clouds at dawn, drawn procedurally in pure Python.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024x1024) to the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
